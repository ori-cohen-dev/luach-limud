# לוח לימוד יומי חכם

אפליקציית אינטרנט (PWA) שבונה לוח לימוד יומי: בוחרים מה ללמוד – תנ״ך, משניות, ש״ס בבלי, רמב״ם או שולחן ערוך – ועד איזה תאריך, ומקבלים חלוקה יומית מחושבת.

- האתר: https://oykalmar-cmyk.github.io/
- מדיניות פרטיות: `privacy.html` (האפליקציה לא אוספת מידע; הנתונים נשמרים רק במכשיר)
- קישורי הלימוד נפתחים באתר ספריא

## מבנה

- `index.html` – האפליקציה כולה
- `sw.js` – Service Worker לעבודה offline (בכל שינוי בקבצים להעלות את `CACHE`)
- `manifest.webmanifest` – הגדרות התקנה
- `icons/` – אייקונים
- `fonts/` – פונטים (Frank Ruhl Libre, Assistant; רישיון OFL בשורש)
