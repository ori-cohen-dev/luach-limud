# לוח לימוד יומי חכם

אפליקציית אינטרנט (PWA) שבונה לוח לימוד יומי: בוחרים מה ללמוד – תנ״ך, משניות, ש״ס בבלי, רמב״ם או שולחן ערוך – ועד איזה תאריך, ומקבלים חלוקה יומית מחושבת.

- האתר: https://ori-cohen-dev.github.io/luach-limud/
- מדיניות פרטיות: `privacy.html` (האפליקציה לא אוספת מידע; הנתונים נשמרים במכשיר, ובסנכרון – גם ב-Firestore תחת קוד אקראי)
- קישורי הלימוד נפתחים באתר ספריא

## מבנה

- `index.html` – האפליקציה כולה
- `sw.js` – Service Worker לעבודה offline (בכל שינוי בקבצים להעלות את `CACHE`)
- `manifest.webmanifest` – הגדרות התקנה
- `icons/` – אייקונים
- `fonts/` – פונטים (Frank Ruhl Libre, Assistant; רישיון OFL בשורש)

## סנכרון בין מכשירים

- בלי הרשמה: מכשיר אחד יוצר קוד סנכרון אקראי (`LS-XXXXX-...`), ושאר המכשירים מצטרפים איתו (הדבקה או קישור `#sync=`).
- כל המצב נשמר כמחרוזת JSON אחת ב-Cloud Firestore במסמך `sync/<קוד>`, דרך ה-REST API (בלי SDK).
- כל מכשיר ממזג לפני כתיבה: לכל סימון נשמר זמן (`ct`), החדש גובר; הגדרות תכנית לפי העריכה האחרונה; תכנית שנמחקה משאירה מצבה (`lu-del`).
- ההגדרות ב-`SYNC_CFG` שבראש קטע הסנכרון ב-`index.html`. כשהן ריקות, אפשרות הסנכרון לא מוצגת.
- כללי האבטחה: `firestore.rules`.
